# Источники данных и внешние сервисы

Состояние на конец октября 2026 года. Сервисы меняются — при сбое сначала проверьте, что описанное ещё работает.

## ЕИС (zakupki.gov.ru)

**Какие закупки есть в ЕИС.** 44-ФЗ, 223-ФЗ, закупки по ПП РФ № 615 (капитальный ремонт многоквартирных домов) и архив по старому 94-ФЗ. Парсер не должен зависеть от закона.

**Как получить XML отдельной закупки (для образцов и P2-загрузки по номеру).** XML-представление печатной формы извещения:
`https://zakupki.gov.ru/epz/order/notice/printForm/viewXml.html?regNumber=<реестровый номер>`
Для 223-ФЗ адрес печатной формы другой — уточнить по образцам. Вручную: карточка закупки → «Документы» → иконка печати. Сайт может не открываться с зарубежных IP — собирайте образцы из России и храните в `data/samples/`.

**Массовые выгрузки.** FTP-сервер ЕИС закрыт с 1 января 2025 года. Машиночитаемые данные отдаёт только сервис отдачи информации (SOAP), для него нужен персональный токен из личного кабинета ЕИС, а для токена — электронная подпись. Сервис нестабилен (были ошибки «Токены для сервисов отдачи отсутствуют в ЕИС», адрес менялся с int44.zakupki.gov.ru на int.zakupki.gov.ru). Есть Python-клиент `dars` на PyPI. В первом этапе не используем.

**Лоты.** Единица участия — лот: заявка на конкретный лот, отдельный контракт по каждому лоту, НМЦК на уровне лота. В 44-ФЗ несколько лотов — исключение, в 223-ФЗ зависит от положения заказчика. Позиции внутри лота не делятся: заявка подаётся на весь объект закупки.

## LLM

- Доступ через ProxyAPI (OpenAI-совместимый). Базовый URL и точные идентификаторы моделей — в личном кабинете ProxyAPI.
- **GPT-6 Luna** — самая быстрая и экономичная модель линейки GPT-6 (выпущена 22.09.2026), около $0,10 / $0,50 за 1 млн входных / выходных токенов, поддерживает строгий JSON по схеме.
- **Claude Haiku 5.5** — быстрая модель Anthropic.
- Выбор между ними — по прогону `tests/evaluate.py`; итоговый идентификатор обязательно указывается в README.
