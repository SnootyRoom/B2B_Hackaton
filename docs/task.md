## Задача 4

**Ключевые технологии:** парсинг ЕИС, интеграция ЕГРЮЛ.

**Проблема:** компании-поставщики ежедневно анализируют сотни закупок из ЕИС. Ручная оценка привлекательности каждой закупки занимает часы.

**Решение:** автоматический скоринг закупок на основе данных из ЕИС, информации об организации из ЕГРЮЛ и заданных параметров оценки.

### Примерный воркфлоу

1. Пользователь загружает: выгрузку из ЕИС (.xml/.json), данные из ЕГРЮЛ (по ИНН), текстовую формулировку параметров скоринга.
2. Система парсит ЕИС и извлекает ключевые параметры: НМЦК, тип процедуры, регион, сроки поставки.
3. Интеграция с ЕГРЮЛ: получение данных об организации (ИНН, ОГРН, статус, виды деятельности).
4. ИИ-скоринг: расчёт оценки по заданным параметрам (0–100%).
5. Вывод результатов: таблица с параметрами закупки, итоговая оценка (%), рекомендация.

### Критерии приёмки

| № | Критерий | Метрика |
| --- | --- | --- |
| 1 | Парсинг ЕИС | Корректное извлечение всех ключевых параметров закупки |
| 2 | Интеграция ЕГРЮЛ | Получение данных об организации по ИНН |
| 3 | Настраиваемость параметров | Изменение параметров скоринга без изменения кода |
| 4 | Время расчёта | Скоринг одной закупки < 10 секунд |
| 5 | Вывод рекомендации | Обоснование рекомендации ссылками на параметры |
| 6 | Точность скоринга | Соответствие оценки тестовым сценариям (≥ 80%) |
| 7 | Архитектура | Запуск через `docker-compose up --build` |
