# Демо-набор

- `procurements/` — 48 извещений ЕИС (копии из `data/samples`), у которых срок подачи после 14.11.2026;
  у 14 из них «Осторожный» и «Агрессивный» дают разные рекомендации;
  заказчики — офлайн-профили в `data/customers`.
- `profile.json` — базовый профиль строительной компании (ремонт зданий, 5–50 млн ₽, по всей России).
- `expected.json` — ожидаемые оценки по базовому профилю, «Осторожному» и «Агрессивному»:
  `python tests/demo_check.py --date <день показа>` сверяет и показывает закупки с истёкшим сроком.
- `reg_numbers_offline.txt` — список номеров для загрузки без интернета: все номера есть в `data/samples`.
- `reg_numbers_online.txt` — список для показа с доступом к ЕИС.

## Списки номеров (задача B)

`reg_numbers_offline.txt`: 44-ФЗ `0121200004726001367` и `0848300048226000439`, 223-ФЗ `32616476087`,
многолотовое 223-ФЗ `32616481510` (2 лота → 2 записи), повтор `0848300048226000439`, неверный формат `12345`.
Ожидается: 4 номера загружены (5 записей), повтор не создаёт дубль, `12345` — ошибка «нужно 11, 18 или 19 цифр».
Если ЕИС недоступна, номера берутся из образцов с предупреждением «документ взят из сохранённых образцов».

В ЕИС актуальная редакция `32616481510` — уже с одним лотом (проверено 13.11.2026), двумя записями
он загружается только из образца.

`reg_numbers_online.txt` добавляет несуществующий номер `0348300000026999999` («закупка не найдена в ЕИС»;
без доступа к ЕИС — «портал недоступен») и повтор в конце.

## Сценарий показа (2–3 минуты)

1. **Два профиля.** Экран «Параметры»: базовый профиль строительной компании, из него шаблоном —
   «Осторожный» и «Агрессивный». Показать отличия: стоп на реорганизацию заказчика, суммы без допуска
   против диапазона вдвое шире, пороги рекомендаций.
2. **Переключение с пересчётом.** Сделать активным «Агрессивный»: индикатор пересчёта, затем на
   «Результатах» закупки у краёв диапазона 5–50 млн меняют рекомендацию:
   - выше 50 млн: детсад № 103, Курган (`0843500000226006438`, 53,9 млн) и СОШ № 20, Пенза
     (`0855300002826000790`, 51,5 млн) — «Осторожный»: Рассмотреть, «Агрессивный»: Участвовать;
   - сильно выше: СОШ с. Янтарного (`0304300005026000042`, 64,0 млн) — базовый и «Осторожный»: Рассмотреть,
     «Агрессивный»: Участвовать (диапазон до 100 млн);
   - ниже 5 млн: поликлиника Уренской ЦРБ (`0832200006626000892`, 4,8 млн) и кровля (`32616572792`, 4,3 млн) —
     «Осторожный» без допуска: Рассмотреть, «Агрессивный»: Участвовать;
   - заказчик в реорганизации: ремонт учебно-лабораторного корпуса, Дагестан (`0303500000726000005`, 4,0 млн) —
     базовый: Рассмотреть (50), «Осторожный»: Пропустить (стоп «Заказчик в процессе реорганизации»),
     «Агрессивный»: Участвовать (87);
   - молодой заказчик (1,6 года): `32616556511` — «Осторожный»: Пропустить (42), «Агрессивный»: Участвовать (88).
3. **Сравнение.** Открыть сравнение «Осторожный» / «Агрессивный» на этих закупках: объяснение называет
   правило о сумме или о возрасте заказчика как причину разницы.
4. **Загрузка списка номеров.** Вкладка «По номеру», вставить `reg_numbers_offline.txt`: прогресс,
   статусы по каждому номеру, многолотовая закупка — две записи, повтор не дублируется, `12345` —
   понятная ошибка, остальные номера обработаны.
